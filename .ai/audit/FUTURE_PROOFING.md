# Future-Proofing & Longevity Horizons

A laptop is a multi-year investment. SysPulse projects hardware viability across three explicit time horizons.

---

## 1. Viability Horizons

### 1-Year Horizon (Current Generation)
- **Question:** Can this laptop run current-year applications without memory or compute bottlenecks?
- **Standard:** Virtually all modern laptops pass unless crippled by $<4\text{GB}$ VRAM or $<8\text{GB}$ RAM.

### 3-Year Horizon (Mid-Term Viability)
- **Question:** Will this laptop handle operating system memory bloat, updated game engines, and local 8B LLM OS assistants?
- **Standard:** Requires $\ge 16\text{GB}$ upgradeable RAM and $\ge 6\text{–}8\text{GB}$ VRAM. Soldered 16GB memory drops to `MEDIUM` or `LOW` viability.

### 5-Year Horizon (Long-Term Ownership)
- **Question:** Can this machine survive 5 years of physical wear, battery decay, and software demands?
- **Standard:**
  - Requires modular RAM (dual SODIMM slots) and secondary M.2 SSD expansion.
  - Requires clean chassis serviceability (standard Philips screws, accessible cooling fans for dust cleaning).
  - Takes into account thermal paste pump-out vulnerability on bare copper heatsinks vs long-lasting phase-change materials / liquid metal.

---

## 2. Longevity Classifications
- **EXCELLENT (5+ Years):** Fully modular workstation with dual SODIMMs, multiple M.2 slots, replaceable battery, and robust aluminum/magnesium chassis.
- **GOOD (3–5 Years):** Upgradeable storage and RAM, solid build quality.
- **MODERATE (2–3 Years):** Partially modular (1 soldered + 1 SODIMM slot) or average thermal headroom.
- **POOR (< 2 Years):** Fully soldered RAM, single M.2 slot, glued battery, and plastic hinge anchors.
